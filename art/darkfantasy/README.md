# Сгенерированная графика 1.2.0

Игровые изображения созданы генератором изображений. Оригинальные PNG сохраняются без перерисовки и разрезания. Godot выбирает области `AtlasTexture`, размещает, масштабирует и анимирует готовые кадры. Строительный полигон использует непрерывную земляную поверхность; здания имеют собственные основания и контактные тени.

| Актуальный файл | Содержимое |
| --- | --- |
| `gems_shapes.png` | Шесть однородно окрашенных кристаллов разных форм, 3 × 2 |
| `powers_clean.png` | Горизонтальная/вертикальная молнии, бомба, звезда, 2 × 2 |
| `effects_clean.png` | Взрыв, молния, лёд, пыль: 8 кадров каждого, 8 × 4 |
| `shards_clean.png` | Шесть цветовых рядов осколков, 4 кадра каждого, 4 × 6 |
| `campaign_clean.png` | Лесной босс, выключенный/заряженный алтари, знак региона |
| `regional_objects.png` | Ледяной и вулканический боссы, две печати, реликвия и выход; индивидуальные области исключают соседние изображения |
| `forest_background.png`, `ice_background.png`, `lava_background.png` | Три портретных боевых фона |
| `home_background.png` | Кинематографичный главный экран |
| `colony_terrain.png` | Непрерывный земляной полигон без плавающих площадок |
| `mine_structures.png` | Рудный участок, шахта, лесопилка, кристальная шахта, крепость, кузница, башня, склад, тележка, 3 × 3 |
| `bunker_stages.png` | Раскопка, фундамент, стены, готовый бункер, 2 × 2 |
| `colony_workers.png` | По 8 кадров ходьбы в обе стороны, переноски в обе стороны и добычи, 8 × 5 |
| `settlement_clean.png` | Иконки камня, дерева и эссенции из первоначального строительного атласа |
| `ui_nine_slice.png` | Панели и кнопки с прямыми краями для 9-slice |
| `contour_edges.png` | Сгенерированные прямые края и углы фигурного поля |
| `digits_clean.png` | Цифры 0–9, плюс и умножение |
| `seals_clean.png` | Каменная печать, выбор, монета и прежний ледяной вариант |
| `background.png`, `icon.png` | Вспомогательный фон и Android-иконка |

Прежние `gems*` (кроме `gems_shapes`), `ui.png`, `ui_clean.png`, `digits.png`, `board_frame.png`, `campaign.png`, `powers_readable.png`, `effects.png`, `settlement.png`, `settlement_background.png`, `settlement_background_clean.png`, `buildings_extra.png` сохранены для сравнения и исключены из APK.

Рамки используют NinePatchRect: углы исходного листа 54 × 54 отображаются как 27 × 27 пикселей макета; меняется длина прямых краёв. Контур поля собирается из `contour_edges.png` вдоль маски и отверстий и не перестраивается при каждом ходе. У рабочих выбирается область внутри ячейки с отступом четыре пикселя, исключающим линии разделения генерации; исходник не изменяется. Земляная опора зданий закреплена в общей точке, порядок отрисовки зависит от высоты ног.

Числовые счётчики — сгенерированные цифры. Длинные подписи используют DejaVu Sans/Serif из `art/fonts`, лицензия лежит рядом. Изображения не рисуются шрифтом или кодом.
