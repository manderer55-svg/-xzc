# Generated artwork / Пепельный предел

Весь игровой арт создан инструментом генерации изображений в этой задаче, в одном направлении: готический обсидиан, состаренная бронза, фиолетовая и бирюзовая магия. Исходные PNG сохранены без перерисовки. `scripts/art.gd` выбирает регионы через `AtlasTexture`; атласы не разрезаются и не заменяются нарисованными кодом фигурами.

| Файл | Содержимое |
| --- | --- |
| `gems.png` | 4 × 4: шесть кристаллов, четыре усилителя, камень, лёд, ячейка, выделение, монета, портал |
| `ui.png` | Восемь сгенерированных панелей: шапка, игровая панель, две кнопки, результат, ресурсный блок, шкала, слот |
| `effects.png` | 4 × 4: по четыре кадра взрыва, молнии, разбитого льда и осколков |
| `settlement.png` | 3 × 3: земля, каменоломня, лесопилка, святилище, крепость, три ресурса, портал |
| `digits.png` | 4 × 3: золотые цифры 0–9, плюс и знак умножения для числового HUD |
| `background.png` | Портретный фон поля: руины, готические арки и туман |
| `settlement_background.png` | Портретный фон отдельного строительного полигона |
| `icon.png` | Иконка Android с аметистом в готической оправе |

Итого **64 элемента** из восьми оригинальных генераций. Текстуры с альфа-каналом у спрайтов и панелей. Цифры основных счётчиков — тоже сгенерированные спрайты. Русские подписи, обучающие сообщения и длинные динамические тексты набраны лицензированным DejaVu Sans из `art/fonts` для читаемости и локализации; игровые иллюстрации не создаются шрифтом.

Эффекты используют кадры этого атласа, масштабирование, вращение и прозрачность. Геометрия поля, логика совпадений, размещение объектов, подписи и анимация управляются кодом. Это сохраняет исходный арт и позволяет делать уровни любых поддерживаемых форм.

`art/preview` — снимки действительно запущенной игры, не отдельные нарисованные макеты. Старые яркие конфетные PNG в `assets` оставлены из предыдущей задачи и не используются в этой игре.
