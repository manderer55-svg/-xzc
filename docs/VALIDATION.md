# Проверка 1.2.0

Проверено в облаке: Godot 4.6.3, JDK 21, Linux, Compatibility renderer / Mesa llvmpipe. Команда `bash tools/check.sh` завершилась успешно.

| Проверка | Результат |
| --- | --- |
| Движок, первые 1000 рецептов, спецобъекты, падение | 64 370 проверок |
| Прогресс, награды, миграция старых данных, восстановление | PASS |
| Шесть целей, боссы и прогноз ходов | 5 881 проверка |
| Переиспользование сгенерированных цифр | 4 004 проверки |

| Пулы фишек и эффектов | 7 574 проверки |
| Реликвии, три региона, кузница/башня, звук, цветные осколки | 4 132 проверки |
| Маршруты рабочих, доставка, резервации, улучшения, бункер, откаты сохранения | 60 проверок |
| Настоящая главная сцена | UI_SMOKE_OK |

Сценовый сценарий проходит настоящий ввод на шести кнопках выбора зданий, строительстве и прозрачных областях построек. Проверяет, что строительство не меняет бонусы активной попытки; симулирует движение рабочих до доставки, строит три этапа бункера и проверяет переключение звука. Используется отдельное тестовое сохранение.

Автоматический игрок с прогнозом на один ход выиграл **56 из первых 60 уровней (93,3%) без бонусов зданий**, включая все шесть боссов. Неудачные попытки: 5 и 45 (реликвия), 14 (алтари), 48 (печати). Это выборка для баланса, а не доказательство прохождения всех 1000 уровней человеком.

Снимки получены из работающей сцены через `bash tools/render_previews.sh` при 720 × 1280 и `ASHEN_PREVIEW_RESOLUTION=450x800 bash tools/render_previews.sh`. Углы рамок дополнительно сравниваются по пикселям: 27 пикселей, максимальная разница каналов 0, 89 проверок. В финальных запусках нет ошибок GDScript, отсутствующих ресурсов или утечек при завершении. Предупреждение о невозможности переключения V-Sync относится к виртуальному дисплею.

Android-сборка: пакет `org.ashenveil.match3`, версия 1.2.0, versionCode 4, ARM64/ARM32, Android 7+, API 36. Проверяется неизменность сертификата относительно 1.1.1, подписи APK v2/v3, ZIP-выравнивание 16 КБ и ARM64 LOAD-сегменты 0x4000. Размер и SHA-256 указаны в [ANDROID.md](ANDROID.md) и [файле контрольной суммы](../downloads/ashen-veil-debug.apk.sha256).

Подключённого Android-телефона нет. Реальная плавность, нагрев, память и обновление приложения требуют проверки по [DEVICE_CHECKLIST.md](DEVICE_CHECKLIST.md). Google Play и восстановление облачной среды в новой задаче не проверялись.
