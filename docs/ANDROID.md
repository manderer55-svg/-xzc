# Android: Пепельный предел 1.3.0

Godot 4.6.3, портретный макет 720 × 1280, Compatibility / OpenGL ES 3.0. Пакет `org.ashenveil.match3`, версия `1.3.0`, versionCode `5`, ARM64 (`arm64-v8a`) и ARM32 (`armeabi-v7a`). Android 7.0 / API 24 и новее; целевой API 36.

## Сборка

```bash
cd /workspace/-xzc
bash tools/setup_android.sh
ASHEN_BASELINE_APK=downloads/ashen-veil-debug.apk bash tools/export_android.sh
```

Нужны JDK 17/21, curl, unzip, Python3 и стандартные команды проверки хешей. Toolchain размещается вне checkout в `/workspace/.tools/ashen-veil`, загрузки — `/workspace/.cache/ashen-veil-downloads`. Скрипты проверяют официальные Godot export templates по SHA-512 и Android SDK по SHA-1 из метаданных Google, сохраняют TLS-проверку и доверие сертификатам среды. Повторный экспорт после setup работает без сети. Gradle/NDK для этого debug APK не требуются.

Результат: `builds/ashen-veil-debug.apk`; распространяемая копия — `downloads/ashen-veil-debug.apk`. Скрипт проверяет пакет, подпись и versionCode относительно предыдущего APK, затем подписи v2/v3 и ZIP-выравнивание 16 КБ. Ключ хранится вне Git. Новый ключ не обновит ранее установленное приложение.

Установка обновления: `adb install -r downloads/ashen-veil-debug.apk`. Удаление приложения стирает локальный прогресс. Код версии увеличен `4 → 5`; экспорт сравнивает сертификат с прежним APK 1.2.0. Модельные проверки миграции пройдены: девять зданий сохраняются в городе с 64 участками, не доставленная добыча переносится в конечные месторождения. Реальное обновление проверяется на телефоне.

## Артефакт

Размер: 95439575 байт. SHA-256:

```text
a7114396c56b35f4d1eeb48920aad96519236b5a069a388aee38279f39d68c69
```

В экспорте используются 25 актуальных сгенерированных изображений, семь звуков, три шрифта и лицензия. Новые листы содержат изометрическую землю, растительность, 15 типов зданий, воинов, портреты и анимации героев, этапы бункера. Предпросмотры, документация, тесты, предыдущие варианты графики, ZIP и прежний APK исключены. Проверено содержимое APK: 25 PNG-импортов, семь WAV-импортов, три шрифта и лицензия. Подписи v2/v3 и ZIP-выравнивание 16 КБ прошли проверку; обе ARM64-библиотеки имеют LOAD-выравнивание 0x4000. Сертификат совпадает с версией 1.2.0. Контрольная сумма также публикуется в `downloads/ashen-veil-debug.apk.sha256`.

## Память и телефон

Сумма `ширина × высота × 4` для 25 исходных PNG — 157 294 040 байт, около 150 MiB при одновременной загрузке RGBA8. Это оценка, а не измерение RAM/GPU на Android. Lossless-импорты без mipmaps; AtlasTexture разделяет исходный лист между спрайтами, кадры не создают отдельную полную копию каждого изображения. Движок, шрифты и буферы требуют дополнительной памяти.

Переиспользуются 81 фишка, 24 эффекта (8 в экономном режиме) и восемь звуковых голосов. У города 64 строительных участка; на ресурсной карте одновременно отображаются до четырёх героев и 12 воинов в четырёх отрядах. Обе карты состоят из 900 клеток, готовые текстуры переиспользуются, объекты за пределами камеры скрываются. Скрытая карта не анимирует персонажей; назначенные походы сохраняются и продолжаются через модель времени.

Проверяйте FPS, память и нагрев на одном телефоне и одинаковом сценарии по [DEVICE_CHECKLIST.md](DEVICE_CHECKLIST.md). Для Google Play понадобится release key и AAB; публикация не выполнялась.
