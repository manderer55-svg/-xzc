# Android: Пепельный предел 1.2.0

Godot 4.6.3, портретный макет 720 × 1280, Compatibility / OpenGL ES 3.0. Пакет `org.ashenveil.match3`, версия `1.2.0`, versionCode `4`, ARM64 (`arm64-v8a`) и ARM32 (`armeabi-v7a`). Android 7.0 / API 24 и новее; целевой API 36.

## Сборка

```bash
cd /workspace/-xzc
bash tools/setup_android.sh
ASHEN_BASELINE_APK=downloads/ashen-veil-debug.apk bash tools/export_android.sh
```

Нужны JDK 17/21, curl, unzip, Python3 и стандартные команды проверки хешей. Toolchain размещается вне checkout в `/workspace/.tools/ashen-veil`, загрузки — `/workspace/.cache/ashen-veil-downloads`. Скрипты проверяют официальные Godot export templates по SHA-512 и Android SDK по SHA-1 из метаданных Google, сохраняют TLS-проверку и доверие сертификатам среды. Повторный экспорт после setup работает без сети. Gradle/NDK для этого debug APK не требуются.

Результат: `builds/ashen-veil-debug.apk`; распространяемая копия — `downloads/ashen-veil-debug.apk`. Скрипт проверяет пакет, подпись и versionCode относительно предыдущего APK, затем подписи v2/v3 и ZIP-выравнивание 16 КБ. Ключ хранится вне Git. Новый ключ не обновит ранее установленное приложение.

Установка обновления: `adb install -r downloads/ashen-veil-debug.apk`. Удаление приложения стирает локальный прогресс. Сохранён прежний сертификат 1.0/1.1/1.1.1, код версии увеличен `3 → 4`. Модельные проверки миграции пройдены; реальное обновление проверяется на телефоне.

## Артефакт

Размер: 89658589 байт. SHA-256:

```text
509ed6a5884e1660bf65ed45d79ce3686855b63b3ab47eb47ee90383c56caf4e
```

В APK — 21 актуальное сгенерированное изображение, семь звуков, три шрифта и лицензия. Предпросмотры, документация, тесты, исходные генерации предыдущих вариантов, ZIP и прежний APK исключены. Обе ARM64-библиотеки имеют LOAD-выравнивание 0x4000. Контрольная сумма также находится в `downloads/ashen-veil-debug.apk.sha256`.

## Память и телефон

Сумма `ширина × высота × 4` для 21 исходного PNG — 132 125 688 байт, около 126 MiB при одновременной загрузке RGBA8. Это оценка, а не измерение RAM/GPU на Android. Lossless-импорты без mipmaps; AtlasTexture разделяет исходный лист между спрайтами, кадры не создают отдельную полную копию каждого изображения. Движок, шрифты и буферы требуют дополнительной памяти.

Переиспользуются 81 фишка, 24 эффекта (8 в экономном режиме), девять рабочих и восемь звуковых голосов. Колония не анимируется, когда скрыта. Проверяйте FPS, память и нагрев на одном телефоне и одинаковом сценарии по [DEVICE_CHECKLIST.md](DEVICE_CHECKLIST.md). Для Google Play понадобится release key и AAB; публикация не выполнялась.
